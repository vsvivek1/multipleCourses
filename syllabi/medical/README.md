# Medical specialist syllabi (Kerala PSC)

Official detailed syllabi from keralapsc.gov.in (Postwise Syllabus list), one per post.
`sources.csv` maps each post to its official PDF. The `Fetch Kerala PSC syllabi`
GitHub Action downloads each PDF to `<slug>.pdf` and extracts text to `<slug>.txt`.

Notes:
- **Neurology**: no standalone Assistant Professor syllabus is listed. The file is the
  2016 combined NCA notice (Programme 11/2016) whose cover lists Neurology; neurology
  topics sit under section 11(n) "Central nervous system".
- **Urology**: the newer Aug 2025 syllabus (Cat. No. 009/2025) is used.
- **Dental Assistant Surgeon**: Health Services post, not Assistant Professor.
